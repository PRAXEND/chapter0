# Video Studio for Mac

本地视频工作台提供选题成片、脚本混剪、原声访谈精剪三个入口。项目中的对话、手工时间线、风格样板与审片共用帧时钟和版本记录。选题可填写出处网页和媒体直链。正常渲染直接写出 MP4、SRT 和便携工程，启用发布包可附两种封面及文案。

## 使用

在 Apple Silicon Mac 打开 Video Studio.app。首次用“本机与账号”连接自己的 Codex 账号。“新建工程”可以直接开始制作，也可先导入文件。模型准备与生成进度显示在工作台。首次使用转录或克隆时会下载对应本机组件。点击“本地粗剪”可从已有素材生成草稿。互联网选材使用登记的公开媒体接口或用户选择的直链。

- 在素材预览中登记动作发生的原片帧。时间线上点片段可改起点、原片窗口、内容、速率、音量和锁定。渲染后可以在播放头处分割画面。精剪原片支持按句试听及按原片顺序恢复。选中镜头可直接回看原素材区间。制作中可看当前版本的六秒草稿，也可发新指令给进行中的 Codex 回合。
- 工程设置可选同期声、系统声音、已录旁白或克隆。在本机登记已获授权的参考录音、准确原文并试听。原声、参考音频和媒体文件保存在本机。选择“允许分享参考帧”可让 Codex 读取受控抽帧。关闭转录分享时，本机识别的画面文字也不会传入模型。
- 风格库可播放经过指纹核验的参考片。单个参考视频可在本机分析并抽取带源时间码的代表帧。保存个人改稿偏好会生成新版，附改动前后两段可播放样例。已固定版本的工程可继续打开。历史入口支持按原指纹导入原素材或旧成片，以及打开已登记的旧编辑工程。
- 选择 Henry 技术科普 v8 或热点资讯 v8，工程默认登记正式的本地 Dylan 旁白，按风格仅作一次 1.2 倍保音高变速。在工程设置可指定同期声、录音、已授权克隆、系统声音或仅试听。科普版取用 Kevin MacLeod 的《Wallpaper》，发布包保留 CC BY 4.0 署名。热点版从原工程生成记录与指纹找回《陌生厨房｜热血节拍纯音乐》。选择自有音乐或关闭配乐均优先于风格默认。
- 在动效菜单中可编辑科普的 6 个原组件、热点的 7 个原组件。移动出场时刻会同步移动绑定的短音效，可在图层内选声音、关闭声音，也可直接修改或锁定音效。热点震屏支持调整发生帧、强度和频率；视频入场可选甩镜或纹理溶解。
- 选择带有技术科普分步语法的风格并授权参考帧后，Codex 会接收基准帧、已导入的源帧，再复看真实合成帧。风格要求运动画面作主体时，选题入口会查找录像并记录实际使用的原片区间。明确要求只用照片时，可在原图上用可编辑的取景和空心框逐处讲解。事实出处和画面出处可分别保存。
- 解释机械动作或材料截面时，各部件可以使用独立的矢量轮廓与关键帧。点选图形可改顶点。比较同处前后画面时，先将两个镜头对齐并短暂叠放，在后一个镜头选择“向右擦除对照”，再设置转场帧数。
- 剪辑台标出每版的创作引擎。本地粗剪保存在工程草稿中，用户可以手动导出。交付记录可分别查看文件验收和运动画面的执行情况，直接播放问题区间。
- 在剪辑台选择镜头，从时间线的动效菜单插入动词强调、来源标识、阶段路径、三步跟随、纵条聚字或分屏标识。可编辑各句、字体、颜色、尺寸、入点和退点。在“三步跟随”的第二步拖动帧滑块，再点击“保存并预览落点”，即可从这句出现前半秒看片。相互叠放的片段可用“选择片段”逐个选中。
- 在画面片段的“画面窗口与分屏”选择右窗素材并点击并排。两侧均可独立调整原片入点、速率、取景和画布窗口，新增右窗默认静音。图形关键帧的 rotation 使用顺时针角度，支持负值和多圈旋转。正式交付会针对组件、分屏和旋转层抽检同版本六秒草稿与导出文件的对应区域，并列出具体工程帧。
- 等待中或运行中的任务可暂停。恢复后重用冻结版本或同一个 Codex 回合。中断时无法核实回执的第三方付费请求会在项目内保留，由用户核对后继续。关闭窗口可继续后台工作，用应用菜单退出会保存任务进度。
- 在“交付”播放带问题时间点的原速片段。机器验收支持可交付、可交付有建议、待复核和需修复。正式成片默认保存到“影片/Video Studio/交付”。“可编辑工程”文件夹内含 project.vstudio.json 和媒体。复制整个文件夹后，可在“新建工程 → 打开工程文件夹”恢复。
- 点击“看片盲评”可直接打开已准备的本机研究，或从当前工程创建校准、留出、风格及成对研究。审片人各用自己的代号、看片后独立作答。真实人审计数和机器判定分别展示。

## 开发与构建

需要 Node 24 和 Apple Silicon macOS。构建还需要 Xcode Command Line Tools、Git LFS 与 Rust。基本程序的 macOS 二进制最低版本为 13.5，Apple Silicon 本地克隆需要 macOS 14 或更新版本。实机验证平台是 8 GB M1、macOS 26.5.2。

```sh
cd apps/studio
node src/server.mjs
node --test test/*.test.mjs
node scripts/test-webview.mjs /tmp/video-studio-webview.png
node scripts/prepare-media.mjs all
node scripts/build-mac.mjs
```

Node 服务只监听环回地址。命令行启动时会显示一次性本地入口。Tauri 内置 Node、Codex、FFmpeg/ffprobe、可用的 whisper-cli 与公开风格包；已发布的风格媒体按 Git LFS SHA-256 和大小物化。构建从官方 npm 包取得固定版 Codex 并验证 SHA-512。本地包采用 ad-hoc 签名。对外分发需要发行方自己的 Developer ID 签名与 Apple 公证。

默认资料库位于 ~/Library/Application Support/Video Studio/standalone。设置 STUDIO_BUILD_CHANNEL=quality 和独立的 STUDIO_DIST 可生成质量验证版，Finder 用独立应用标识启动，默认打开同目录下的 standalone-quality 资料库。STUDIO_DATA_ROOT 可以选择独立资料库，STUDIO_DELIVERY_ROOT 可选择导出目录。模型缓存由 VIDEO_STUDIO_MEDIA_HOME 指定。STUDIO_START_VIEW=blind 可直接打开盲评室，STUDIO_REVIEW_ROOT 可指定另一套研究库。prepare-media 的 render、speech、clone 子命令可分开运行。

## 工程与恢复

SQLite 保存当前工程、不可变编辑版本和任务。素材按 SHA-256 导入工程目录。用户与 Codex 共用带 baseRevision 的原子剪辑命令。每个任务冻结创作证据和时间线，渲染时发生的新修改属于下一版。临时输出与正式交付分开保存；审片证据关联实际 MP4/SRT 指纹。新资料库通过 OS 支持的数据库锁协调单写入服务。项目设置和密钥各自管理，ElevenLabs 密钥仅用于当前进程。原创配乐先登记服务商回执与曲目编号，并用已有本地文件指纹恢复结果。服务商音乐生成历史尚未开放 API，无法辨认的账单需由用户核实。[ElevenLabs 历史接口](https://elevenlabs.io/docs/api-reference/history/list)

时间线的手工操作按提交批次写入本工程的撤销记录。工作台重新打开后可接着撤销、重做。每次回退产生新版本，恢复本次涉及的片段属性，保留此后的素材、设置、任务和其他剪辑。后续改动与本次涉及的源窗口或属性冲突时，工作台保留当前版本并指出片段。开始新的手工编辑会清除已撤销操作的重做记录。打开便携工程会建立新的工程和撤销记录，升级前的工程从首次新编辑开始记录。

`POST /api/projects/:id/edits` 接收 `{baseRevision,commands}`。移动使用 `{op:"move",id,start}`。裁切使用 `{op:"trim",id,edge:"start"|"end",atFrame}`，结束帧不计入区间。分割使用 `{op:"split",id,atFrame,newId}`。同轨波纹删除使用 `{op:"ripple-remove",id}`，同轨后方片段向前移动，已绑定的音效跟随所属图层。同轨重叠或遇锁会取消整批修改。完整 JSX 组件保留自身时钟，可移动或用组件参数另行编排出场时间。

录像和音轨使用 `{op:"speed",id,speed}` 调整到 0.125 至 8 倍。工作台保留源入点和出点，把时长取为可用的最近整帧，再返回实际速率。工程起点、时长和裁切位置均为整数帧。变速后分割得到的原片入点可含小数，采样窗口随工程保存。取景、画面适配、音量、静音等继续通过 `update.changes` 编辑。

`GET /api/projects/:id/history` 返回版本、可执行状态、操作名及冲突原因。向同一工程的 `/undo` 或 `/redo` 提交 `{baseRevision}`，即可取得新版本工程。旧版本、已改变的同一属性和锁冲突均返回 HTTP 409。运行 `node --test apps/studio/test/timeline-edit.test.mjs apps/studio/test/project.test.mjs` 可复验持久记录、来源时钟、锁与并发。本机已有 Atlas 基准片时，运行 `node --test apps/studio/test/timeline-source-phase.test.mjs` 会把一段 1.25 倍速镜头分成两段，比较正式滤镜输出的 44 个画面校验值和 70,400 对立体声采样。所有比较在内存中进行。

媒体适配器和模型准备见 scripts/prepare-media.mjs。已授权的公开技术样片可用 scripts/media-proof.mjs 复做，scripts/open-proof-project.mjs 可将该样片导入独立工程、以真实 Codex 重写一处字幕并校验其余编辑对象。研究使用的前台配对条件见 test/foreground-comparison.md。

### 在现有素材内制作和回看首版

将工程的 `settings.sourceScope` 设为 `project`，选题、首剪、复剪都只能使用已导入的素材和已登记的事实出处。允许参考帧分享时，导演可指定原片秒数，比较该时刻前后带时间标签的连续帧。风格复看按导演实际采用的阶段进行。用户明确要求四阶段时，工作台会核对四阶段。每次提交剪辑后，导演可读取完整时间线和实测旁白结束时刻，核对目标片长与简报中明确给出的全片时长范围。

自动复剪从首版任务登记的 MP4 读取画面。工作台先核对工程、版本和文件指纹，把首尾、切点与验收问题附近的样帧发给 Codex。复剪时可以在同一秒分别查看首版和修改后的时间线。验收反馈包括声音轨道和已做过的混音检测；若允许分享转录，也可提供本机从最终混音识别的带时间码文本。Codex 收到的是这些观测和图像，主观听感由能播放音轨的审片人判断。关闭帧分享会保留首版并说明复剪所缺的权限。

两版各自保存。若 Codex 选择保留首剪，复剪记录会注明。中断恢复时，工作台会核对同一回合、首版指纹和最后读到的工程版本；若用户在此后改过工程，会提示从新版本继续。可运行 `node --test apps/studio/test/candidate-inspection.test.mjs apps/studio/test/director.test.mjs apps/studio/test/codex-transport.test.mjs` 复验成片抽帧、范围限制、隐私设置与并发编辑。

### 风格成片的独立终审

启用自动回看与画面分享后，v8 技术科普、热点资讯及使用对应视觉规则的工程会在复剪成片冻结后进入独立终审。一个新的 Codex 会话比较实际导出的开头、科普解释或新闻行动发展、结尾，以及锁定版本的风格基准。审片人最多收到 16 张图，可对照局部候选和同一时刻的原片；它只能回传观察。工作台用成片 SHA-256、工程修订、帧号和实际 JPEG 指纹绑定每条记录。主观听感和完整播放体验仍由能看片、听音的人确认。

项目设置 `finalReviewMaxTurns` 默认 1，设为 0 可关闭本次自动终审。关闭画面分享、预算停用或工程版本改变时，交付记录会说明原因。重启后沿用已登记的只读回合；回合登记不明时保留候选。明确的源画面疑点可以定位到时间线，轻微风格建议随可交付候选展示。

复剪只继承在原件、旧成片和新成片上能够重新核实的动作区间。当前同源窗口、旁白位置，以及对应兴趣区前、中、后的图像与实际变化都经过检查。新确认的动作另列独立审片所用的两张成片图与两张同源原片图。验收记录 `evidence.independentReview` 保存完成状态和实际取样，`evidence.visual.motionCoverage.informativeFrames` 是有上述证据覆盖的时间窗总长。v8 竖版的动作和图层复核使用实际居中的素材窗，单独记录其像素边界。外层标题、字幕和动态底纹可在冻结全画幅对照中看到。可用 `node --test apps/studio/test/independent-review.test.mjs apps/studio/test/portrait-review.test.mjs` 离线复验权限、预算、中断恢复、轻重分级和证据刷新。
### 连续试剪与可选审稿

热点资讯 v8 与技术科普 v8 共用连续剪辑流程。一个 Codex 回合可以读选中风格的完整规则或任一蓝图章节，同时看获准分享的基准和原片样帧，先试一段，在真实草稿上核对，再追加、移动或重编多个镜头和旁白。用 `studio_review_cut` 回看改动，再用 `studio_visual_review` 记录该版实际看到的内容即可在本回合结束。导演明确提交待续试剪、要求补入原生图片或另行复看时，可追加一次并在任务进度说明原因。

`studio_sequence` 的 `append` 用于扩剪，`replace-range` 以当前工程的半开帧区间替换完整段落，空分镜可删除所选整段，`replace-all` 重编整片。区间外的语音、字幕、图形、事实出处和源窗连同工程版本一起保存。替换后的段落若会移动后方已锁定内容，工作台会指出冲突，可保留该区间时长继续。需要画面切点落在某个镜头内部时，可先在时间线上分割该镜头。

默认直接制作。需要先看稿时开启工程的 `settings.confirmSequence`。待审方案列出本片实际旁白、素材与源窗，也包含选用的动效和镜头条件。此时工作台尚未合成这份分镜的正式配音。确认绑定方案内容、工程版本、风格和原件指纹；其中一项发生变化需重新核对。冻结首版的自审仍单独记录，可在同一回合对比已导出的首版、原片和最新时间线。

运行 `node --test apps/studio/test/director.test.mjs apps/studio/test/director-contracts.test.mjs` 可验证两类 v8 的主要入口、同回合结束、试剪恢复、手动确认、冻结首版共享、区间重排和实际 SQLite 历史事务。这组测试使用确定性工具响应，未调用线上模型或生成视频。

### 图形旋转与双画面对照

原生图形的 `keyframes[].rotation` 使用度数。正值在屏幕上顺时针旋转，负值逆时针，默认 0。角度按原值插值，所以从 0 到 720 会转两圈。多边形的旋转中心是可编辑框的中心，位置、缩放和不透明度可以同时变化。分割图形时会把切点当时的姿态写入两段。原版 JSX 动效使用其自身的入场与节奏时钟。

要把两路视频并排放在同一段时间，各保留一个 `track:"video"` 片段，将 `viewport` 分别设为 `{"x":0,"y":0,"width":0.5,"height":1}` 和 `{"x":0.5,"y":0,"width":0.5,"height":1}`。坐标以画布左上角为原点。每个片段独立保存原素材、`sourceIn`、速度、窗内 `fit` 或 `framing`、转场及声音。相邻窗口使用同一像素边界。重叠窗口按工程叠放顺序合成；窗口内转场会显示其下方的实际像素。分窗审片列出各可见原片，并在该窗的成片像素中抽查动作。两窗同时播放的一秒按一秒成片时间计算。

运行 `node --test apps/studio/test/composition.test.mjs` 可复验真实帧中的旋转方向、偏移预览、分割、双路节奏、局部转场、独立锁定与审片。旧机智号原工程第 655–913 帧重导后，在原检区逐帧测得上桨净转 −244.09°、下桨净转 +183.55°。本次验证针对原理示意的白色桨叶。机智号实飞录像中旋翼转速、两路拍摄是否同时及实际物理运动，仍应根据原片来源和摄影条件判断。

### 时间线手工剪辑

点标尺或轨道空白处定位，拖橙色播放头连续查看合成画面。左右方向键逐帧移动，空格从当前帧播放或暂停，Home / End 到片头或最后一帧。点击橙色时间码可以输入从 0 开始的工程帧号或 `时:分:秒:帧`。可使用加减号缩放，点「全片」恢复总览；放大后用触控板横向滚动或按住鼠标中键平移。

拖片段中部移动，拖左右边缘改变入点和出点。按住 Shift 或 ⌘ 点选多个片段，可以保持相对位置一起移动、复制或删除。吸附以屏幕像素为容差，能对齐其他轨道的片段边缘和播放头，按住 Option 临时关闭，N 切换。片段的原片长度与锁定状态限制可拖区间。叠放的图层会分行显示。带内部出场时钟的 JSX 组件在检查器里调整长度和出场帧。

S 在播放头分割，Delete 删除，Shift + Delete 删除并收拢同轨后续片段。复制粘贴使用 ⌘C / ⌘V；⌘Z 撤销，⇧⌘Z 重做。每次手势作为一次工程编辑保存。轨道名旁的 M 或 ◉ 可统一静音或隐藏片段，L 锁定该轨现有片段。在「插入素材、字幕与动效」可往播放头放素材或字幕。工程监视器与源素材预览分别使用工程帧和原片时间。
