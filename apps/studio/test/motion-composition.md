# 从工作台复现动效与合成

在 macOS 上准备 Node 24、工作台媒体依赖、Atlas 技术科普基准片和 NASA 机智号首飞录像。下面的命令新建独立资料库，经同源 HTTP 登录、创建工程、上传、编辑、预览和导出。两份原录像只读。接手者可换用能够明显区别的本地原片，左片至少 20 秒、右片至少 31 秒。验证也可指定 `--studio "/path/to/Video Studio.app/Contents/Resources/apps/studio"` 来运行安装包内的服务。

```sh
node apps/studio/scripts/verify-motion-composition.mjs \
  --atlas "/path/to/Atlas-v8.mp4" \
  --flight "/path/to/Ingenuity-first-flight.mp4" \
  --out "/path/to/new-verification-directory"
```

取 Atlas 的第 1 秒与机智号的第 12 秒为原片起点。先制成 24 fps 的两份 19 秒输入，避免异帧率原片的截帧边界影响同源对照。左、右各占画布的一半并完整容纳各自素材。在同一个工程先导出分屏底片，接着加入六份 Henry 原版 JSX 组件和两片带旋转关键帧的桨叶。两片均为示意图形。样片静音。

三步跟随共有三个真实版本。最初的第二句是“观察机身”，第二版换成“两层旋翼朝相反方向转”，第三版将第二句从片段第 24 帧延后至第 45 帧。第三行始终在第 60 帧出现。固定项目第 248 帧为草稿起点，逐一取得正常窗口预览及正式成片，不单独重写 JSX 或生成替代示意。

脚本对六个组件的可见特征、两个视口与正确及对调来源的像素距离、改字前后的逐行像素、出现帧拖动的效果、草稿与整片同帧内容，以及两个白色轮廓的有向角度变动分别作出判定。正式审片记录另行核对版本、时间点和图层。结果和原组件、输入、成片的指纹在输出目录，任一必要检查失败时退出码为 1。渲染、读取媒体或 HTTP 失败会保留已产生的文件。再次运行时请使用新目录。

基线为 `4598e2e`。同一组素材和工程操作在基线上把两条影片显示为同一个全画幅，六个未识别组件显示成白框，改字、延迟前后的三个预览字节相同，白桨在抽检时刻的长轴都约 4.04°。像素读数可以复查具体行为，风格偏好及人工观感由创作者判断。
