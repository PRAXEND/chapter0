# 工作台本轮优化与修复核对

日期：2026-11-03。目标分支：`codex/video-studio-web-workbench`。本地基线 `47eb3b5`，拉取到的远端为 `32a7bbc`。经用户 review 同意，整合版本为 `0.3.0-web.24`，同时保留本轮修复与远端 `0.3.0-web.23` 的风格分发/发现能力。

## 已落到代码的改动

| 用户反馈 / 约定 | 实现与边界 |
| --- | --- |
| 工作台缺少主题入口 | 增加“本期主题／想表达的观点”输入区，持久化到项目；主题改变沿用原确认失效规则。 |
| 搜索词为空 | 空值和纯空格回退到本期主题；两者都为空时明确提示。显式关键词仍保留主题及观点约束。 |
| 不外显 X 定期素材库 | 隐藏完整候选目录及更新入口，只保留已下载素材和本期结果；不删除后台缓存及既有接口。 |
| 数量可以输入 | 1–80 的整数，默认 20；输入、Agent schema、中间检查点和最终结果均限制数量。数量调整不使创意确认失效。 |
| 数量是候选目标兼硬上限 | 不足时至少两轮补搜，明确访问失败、取消、执行时限等例外；来源条数与推荐事件数分开显示，不用无关素材凑数。补搜行为依赖 Agent 执行并如实记录，不保证任意主题必达目标。 |
| 在线搜索加已有缓存，遵守时限 | 向搜索上下文提供有界、去重缓存与当前日期；在线查官方、研究、视频平台。分别核验事件/发布日期与缓存日期；缓存可能过时，旧背景素材只能明确作为补充。 |
| 为什么原始来源都是 X | 事实依据链接与视频、图片、音频素材来源分开；事实依据优先呈现官方/研究来源。缺少可用视频明确显示，不把事实网页冒充原片。 |
| 采集点击无反馈 | 提交时即时忙碌反馈、防重复点击；素材卡显示失败原因及重试入口。 |
| 仓库素材规格误判 | 同时探测视频流和容器时长，允许元数据符合其中一种口径；哈希、字节、尺寸、区间及完整解码检查仍保留。 |
| 风格参考校验失败 | 保留严格校验；错误定位到 referenceChecks 下标和字段，动态约束真实参考及已选素材 ID，加入不写入方案的预校验。 |
| 失败文案丢失/反复重做 | 保存草稿和错误记录，最多两轮自动修正，仍失败就拦截；不自动批准、不编造参考观察。 |
| schema 字段约束串扰 | 以 JSON 序列化深拷贝隔离共享字段对象，参考枚举不污染文案、观察等其他字符串，也不污染下一次任务。 |
| 空工程被误认为已经剪辑 | 增加“工程与连接”阶段，同方案恢复显式带已有工程；不以空时间线预览作为素材导入的必经门槛。 |
| 断连后重复制作 | 要求先核对已有项目/素材/任务再有限恢复；使用同一工程的官方认证入口；技术上传恢复与权限拒绝分开。恢复规则不能消除外部断连。 |
| 进度/错误误导 | 限定本轮 jobId 和更新时间；识别 MCP result.isError，保留脱敏错误，成功恢复对应操作后清除连接提示。 |
| 渲染完成但没有文件 | 单列待下载请求与用途；恢复时按 renderId 和文件名复用，不重复配音/重建工程/重新提交导出；实际落盘和声画验收仍是交付条件。 |
| 插件发布文件遗漏 | 新模块和测试加入 workbench/files.json 白名单；本机依赖、凭据、运行目录不进入源码提交。 |
