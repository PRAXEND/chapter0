# 插件内置 Video Studio 网页工作台

网页完整包含于本插件 `workbench/`。安装后可调用 `$open-video-workbench`，通过 `scripts/open-workbench.mjs` 启动或复用本机服务，再由宿主打开返回地址。该入口启动的服务在后台运行。双击本目录 start-macos.command 则以前台终端方式运行，关闭对应终端会停止该实例。安装本身不自动启动服务或制作视频。

项目、缓存与用量默认保存在用户应用数据目录 Video Studio/workbench；macOS 为 ~/Library/Application Support/Video Studio/workbench。设置 VIDEO_STUDIO_WEB_DATA 可使用已有目录。升级插件不覆盖这些数据。

# Video Studio 网页制作工作台

真实工作流：风格与素材 → 文案和分镜 review → 确认当前方案 → 调用 Video Studio / hosted ChatCut 制片 → 指定本地目录交付。每次动作运行独立、临时 Codex 会话，通过同一插件运行目录和哈希记录衔接。

## 启动

```sh
node start.mjs
```

打开 http://127.0.0.1:4317。Node.js 20+，Python 3.10+，Codex CLI 已登录，Video Studio 与 hosted ChatCut 已安装/连接，FFmpeg/ffprobe/yt-dlp 可用；仓库直接采集使用系统 curl（遵循已有代理环境，不读取账号凭据）。不需要 npm install。本插件以 macOS 为当前支持平台。CLI 或 Python 路径可分别通过 `VIDEO_DEMO_CODEX_BIN`、`VIDEO_STUDIO_PYTHON` 指定；插件根目录通过 `VIDEO_STUDIO_PLUGIN_ROOT` 指定。工作台优先查找所在插件根目录，安装后的完整插件自带所有网页代码。

## 运行环境前检

工作台进程在持久数据目录运行，CLI 诊断也显式使用有效运行目录，避免插件缓存被更新或移动时继承失效目录。登录与参数检查分别报告结果，超时保持未知，不误报账号退出。

每次独立执行显式设置 `mcp_optional_startup_grace_ms=0`，等待 MCP 在各自启动时限内完成初始化后再构建工具目录，避免 ChatCut 尚未加载就开始制片。此参数只作用于本次执行，不改用户配置、服务地址或认证。连接检查仍须实际调用 hosted ChatCut `list_projects`；CLI 登录或插件安装成功不能代替这项证据。修复连接后复用原 run 和有效确认哈希继续，无需重新审稿。

每次 Agent 任务前解析实际 CLI 绝对路径、版本、登录和必需执行参数，再用同一 CLI、同一工作目录的只读 config/read 与 model/list 核对当前模型。支持基线为 0.153.0；它是工作台策略，不能代替所有模型的实际兼容要求。未显式指定时从 PATH 和官方应用候选中选择较新版本；VIDEO_DEMO_CODEX_BIN 显式指定时只检查该路径。模型固定为已核验的用户配置，不降级、不改 Codex 配置。服务明确要求更新时停止并锁住相同路径/版本/模型组合，更新后重新检测。

选材页展示 CLI/模型、Python 与 HTTPS、FFmpeg/ffprobe、GitHub 和下载工具的检查状态。搜索需要下载/媒体能力；单条采集按来源检查，复用缓存和本地导入只检查媒体能力；固定版本公开仓库媒体直采检查 curl 与媒体工具，不依赖 CLI/yt-dlp/gh 登录，更新仓库目录另验 gh。缺失不启动 Agent。补齐下载依赖按钮只调用插件固定 bootstrap，在独立虚拟环境安装要求的 yt-dlp，并复检；系统工具和登录问题给出对应修复方式，不在制作中反复安装。各步骤只复检需要的能力，其他项保留其实际检查时间。

写入任务使用 CLI 的 `--approve-for-me`，保留 workspace-write 边界，并把需要批准的工具请求交给原生自动审批；连接检测仍用 read-only。启动前核验该参数实际可用，不支持时提示升级。审批拒绝照实显示，不改用户或插件权限，不追加跳过审批/忽略规则的参数。参见 [官方 CLI 参数](https://learn.chatgpt.com/docs/cli/reference)。

文案页可在用户明确委托时勾选“本次由 Agent 代为审阅并确认”，保留实际委托原话后确认。默认仍为直接点击确认；委托记录不会免除工具权限审查。

## 功能

- 读取真实个人风格名称、版本与验证状态。直接展示真实风格的规则、检查方法、参考案例与证据边界；未导入的仓库风格包可显式选用，通过卡片选择本期真实风格；不自动保存默认。
- 「按插件搜索素材」明确调用 `video-source-tools`，读取真实 skill、适用来源参考和本期风格快照，先保存素材需求，再检索、核实、按事件去重推荐。机器人资讯优先检查 skill 配置的每日 X 仓库，再按缺口使用官网、研究页和 YouTube；其他题材按真实需求选择来源。
- 网页展示最多五项推荐、完整备选/暂缓记录、日期依据和待核实项；同一事件的多个来源合并，推荐不等于用户已选。候选仅有链接，没有真实预览时明确显示。
- 点击带固定 commit、媒体路径和哈希的每日仓库条目时，直接核对 ready 清单、meta 和 LFS 指针并获取该条目的主媒体，不启动 Agent、不克隆仓库、不下载整批。其他来源继续调用采集 skill，且只传递该条相关的候选与筛选记录。按适用来源规则有界下载到运行目录，或复用校验一致的已有文件。仓库素材保留 commit/路径；本地预览中可查看实际保存位置、打开文件夹、下载文件。添加公开链接、上传或从本机路径导入仍可用。
- 搜索中按批次写入 job 独有的 source-progress.json 并持久缓存候选，页面轮询及时更新；即使随后失败、取消或超时，已经保存的候选仍可浏览。中间记录明确待核实，不自动下载、勾选或冒充完成筛选。重启只恢复匹配该任务、题材、风格和 run 的有效结构化检查点。
- 搜索候选也会持久缓存：完成搜索后保存元数据，启动时回填历史 `source-searches/*.json`；同一来源去重并保留多次检索上下文、日期、推荐理由和待核实项。元数据不会带入本地文件状态或触发下载。
- 素材缓存包含「全部 / 未采集 / 已下载」筛选与本地检索。点击未采集候选后只调用该内容的采集流程；成功文件经校验入库后才显示为本地素材，不自动勾选或制片。失败和中断可重试，已有文件直接复用。无需手填主题，点击采集以该候选标题建立采集上下文。
- 本地素材库独立于本期项目：采集或导入后自动复制到 `.data/material-library/`，按实际 SHA-256 去重。打开页面直接显示缓存，支持本地检索、预览与明确选用；新建项目仍保留。选用时再校验并复制到当前 run，自动勾选，但不启动文案或制片。文件已移走或变化会显示不可用。
- 文件经过实际媒体流、时长和哈希校验，视频提取缩略图；网页播放本地预览，采集完成后才可勾选。
- 根据本期风格、真实选材生成文案和分镜，支持修改文案、画面、文字、源映射与预计时段。保存带版本方案；普通流程由用户点击确认，明确委托 Agent 审阅制作时记录委托依据与所审方案，不冒充用户亲自点击。
- 文案审阅区区分「待补输入」和「已知限制与处理」。当前镜头或文案确实需要但未取得的输入会阻止确认，并在按钮旁解释；方案已经避开的说法、未采用的故事需求和保留的观察边界可列入限制，随方案哈希固定并在制作中遵守。
- 制作规格、风格、声音或选材改变后旧确认失效。来源字节改变也会被发现。只改变交付目录不影响创意确认。
- 点击完整制作后，Codex 保留现有插件配置，调用 ChatCut 创建/恢复可编辑工程，按用户启用项处理配音/音乐/字幕，再导出实际文件。没有启用的额外媒体不生成。
- 需要配音时先实时解析已确认的个人音色。账号没有可用克隆音色且尚未选择时，先询问是否克隆：选择克隆后预检创建资格，再提交名称、10–180 秒录音、试听文本和明确授权；选择官方音色后展示实时可试听候选，等待用户选中。声音方向不再授权 Agent 任意代选。不开启配音时不进入此流程。
- 音色输入在当前方案下持久保存；刷新、服务重启与继续制作会复用同一次选择、录音和操作记录。录音校验格式、实际音频流、时长及 25 MB 上限，独立保存在 run/voice-references，不加入共享素材缓存或成片交付。本期选择不覆盖个人默认音色。
- 浏览器相关导入/导出需要用户打开实际工程时，展示工程链接与具体步骤；补充说明后继续既有任务，先查未知操作，不重复提交。
- 真正找到 MP4、核对规格/时长/音轨并完整解码后（要求声音时还检测默认音轨峰值，静音或不高于 -60 dBFS 会阻止交付），才建立交付记录。成片、字幕（启用时）、脚本分镜、来源、工程链接和验收记录保存在用户选定文件夹的新子目录。提供播放、文件下载与打开文件夹。
- 文件校验与完整观看/听审分开；网页不把模型的 `qaStatus:passed` 当作完整感知验收证据。

## Token 用量

右侧 Agent 面板显示本次任务和本项目累计，展开「查看每次任务」可查看生成、搜索、采集、审稿、失败及重试的历史用量和日期。用量来自 Codex CLI 的实际 turn.completed 事件，任务结束后更新；未上报显示未知而非零。输入已包含缓存输入，输出已包含推理输出，总数只计算输入加输出。轻量 tokenUsageJobs 记录独立保存于本机项目，不随详细任务日志超过 50 条而精简；旧项目读取现存真实任务记录，无法还原已丢失的用量。不包含当前聊天和 ChatCut 等第三方服务额度，也不推算费用。

## 项目列表与切换

顶部「我的项目」显示本机保存的项目，支持按名称查找、查看创建/更新时间与制作进度。新建会先保存当前项目；素材选择、方案、确认、任务和成片分别保留，切换回来即可继续。切换与新建前保存当前修改。执行任务时仍可打开项目列表、查看制作步骤、风格规则、素材预览及已保存的交付；修改当前项目、新建及切换到另一个项目暂不可用，避免混用任务结果。顶部持续显示任务、实际已用时间、执行记录和停止入口，结束后自动恢复编辑。不同项目的浏览步骤分别记忆，旧页面不能修改已经切换到的新项目。

项目快照位于 `<工作台数据目录>/projects/<id>.json`；`<工作台数据目录>/workbench-v2.json` 保留当前项目。升级前因新建而丢失网页状态的项目，会尝试从本机现存任务请求、运行目录、方案和已经校验过的交付文件恢复；不重新制作，不凭请求编造任务成功或确认。实际文件需匹配已有哈希，无法还原未保存的旧网页编辑和丢失的执行日志。共享素材缓存继续跨项目可见。

## 状态与恢复

正式状态：`<工作台数据目录>/workbench-v2.json`；插件运行：`<工作台数据目录>/runs/`；每次请求：`<工作台数据目录>/jobs/`。旧 Demo 的 `.data/project.json` 保留，页面与服务备份于 `.data/legacy-demo-backup/`。这些本机内容不进入便携包。

服务重启会标记中断任务。取消本地 Codex 进程不等于取消远端任务，同一已确认方案继续时 Agent 必须读取 run.json 的 project/operation 记录并核对真实状态。进度来自实际工具事件或 Agent 已完成步骤的报告，不显示虚构百分比。

仓库直接采集的运行时限为 3 分钟（单文件至多 350 MB，并遵守 brief 的原片时长预算），失败不自动绕回 Agent 重试；网络请求与下载可取消，残留 .part 会清理。其他搜索、采集与方案生成的运行时限为 15 分钟，正式制作为 60 分钟，连接检查为 5 分钟。超时显示明确的失败原因，与用户主动停止区分；已有素材、画面检查和方案草稿保留，重试先复用匹配记录。点击单条缓存内容采集时只处理该来源，避免重新执行整批搜索。

本期素材和本轮推荐优先展示于完整缓存之前，完成搜索或采集后定位到对应结果。适配当前题材的搜索没有返回完整仓库媒体清单时，同一固定仓库版本的已有清单、原帖文本和日期仍保留；来源缩略图可复用同一版本的真实目录记录。

后端仅监听 127.0.0.1，变更请求校验 Host/Origin 与专用请求头。网络来源拒绝本机/内网 URL；文件预览与下载只能使用登记 ID，对路径做 realpath 边界检查，支持 Range 播放。操作之间串行处理；方案确认前不能启动制作。

## 主要文件

- `studio-server.mjs`：本地服务与交付校验，`server.mjs` 为兼容启动入口。
- `studio-workflow.mjs`：动作约束、输入哈希、方案检查与任务提示。
- `collection.mjs`：固定版本仓库主媒体的有界直采、校验、缓存复用与单条 Agent 上下文裁剪。
- `agent.mjs`：独立 Codex 进程、真实工具事件、超时与取消。
- `plugin.mjs`：调用插件 JSON 适配器。
- `library.mjs`：持久媒体缓存、实际文件校验、历史 run 回填、按哈希去重和独立预览。
- `sources.mjs`：素材 skill 调用约束、事件与推荐校验、实际选材记录。
- `media.mjs`：媒体流、文件边界、公开来源检查。
- `public/`：网页界面。

查看风格不会启动制作或自动导入。选用包内条目时导入所在包，不应用默认偏好；不同版本保持独立，未验证状态不因导入改变。

原 `workflow.mjs` 仅供历史 Demo 回归测试，不参与正式工作台。

网页风格输入使用真实风格卡片；制作要求展示时长上限、画幅、AI 配音、配音偏好、字幕、配乐/原声及输出文件夹。新项目默认开启 AI 配音；已有项目保留原来的声音设置。当前声音模式在规格摘要、审稿和制片页展示，修改后使旧方案确认失效。时长验收使用视频流时长，保留 0.1 秒上限容差，不将 AAC 尾部填充当成视频超时。声音峰值检查仅排除静音/极低音量，不能证明口播完整或混音质量，仍需实际听审。


素材搜索保留 `source-searches/<job-id>.json`、`selection-review.json`、`material-picker.json`，实际复选结果保存为 `material-selection.json`。搜索任务最长 15 分钟，失败或无可用来源会明确展示；没有自动采集整批素材。

旧的工作台运行目录会在启动时回填有效素材；另外的真实插件运行目录可在停止工作台后执行 `node library.mjs --data-dir /absolute/workbench-data --run /absolute/plugin-run` 导入。只读取登记媒体，不扫描全盘，不把仅有链接的候选当作已缓存文件。来源缺少必需校验数据时会保留原因，等待补齐。


## 完整仓库候选与日期浏览

「更新仓库候选」读取当前插件所配置的 `chchenghuiguo-alt/video-daily` 每日仓库。网页服务不能直接使用聊天连接器，因此使用本机已连接的 GitHub CLI (`gh api`)，只读固定 commit 的目录、README、AGENTS、schema、manifest、post 和 meta；不运行仓库脚本。按实际目录读取全部 ready 批次，不限为编辑推荐的 Top 5 或单次搜索的数量。pending 批次显示上传中，读取失败逐项列出。此入口保留完整候选，不按本期题材预先排除；本期针对题材与风格的核实、去重和推荐仍由「按插件搜索素材」执行。

按原帖 `published_at` 在 Asia/Singapore 时区分组、排序和筛选近 3 / 7 / 30 个日历日（含今天）。收集批次、`collected_at` 和本机缓存更新时间另行显示；缺失发布日期进入「日期待核实」，不以批次日期代替。页面每次先展示 24 条，可继续查看剩余内容；本地缓存保留完整目录，刷新或新项目继续可见。

目录更新只读文字元数据；缩略图采用真实仓库图片地址直接显示，不把缩略图当媒体已采集或内容已核实。保存所有媒体的规格与来源哈希；点击某条才按上述直接采集或 skill 流程下载、校验实际文件。相同字节在新的仓库 commit 中仍可复用已下载文件。通用主题搜索每次最多 80 个来源，超出时明确检索范围和后续入口；视频下载来源数/秒数预算独立于候选浏览数量。


## 日间与夜间外观

顶部「日间 / 夜间 / 自动」只调整网页外观；自动模式跟随系统颜色偏好，首次打开默认自动。用户选择保存于当前浏览器的 `frame-appearance`，刷新、打开新项目及返回页面时继续生效；不写入制片 brief 或风格库，也不触发 Agent。浏览器不允许保存时，当前页面仍可切换。页面首次绘制前读取偏好，原生表单、卡片、弹窗、文案编辑与执行面板使用同一组语义配色；来源图片和视频保留原始颜色。

`public/theme.js` 管理外观偏好与系统变化，`public/themes.css` 管理日夜配色和组件层次；`public/styles.css` 保留工作台布局。外观设置在不同电脑与浏览器之间独立，不随便携包携带。

本地导入明确出现执行器断线或租约过期等技术错误时，先核对原 assetId 与任务状态；确认失败且未入库后，使用 ChatCut 官方上传助手恢复。审批或传输权限拒绝仍须停止；不把工程已经打开但桥接断连的情况反复归结为用户未开页面。工具失败事件只保存脱敏且有大小限制的错误原因，不保存参数或结果载荷。
