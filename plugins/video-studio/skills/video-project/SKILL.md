# 视频项目与技能组合

插件根目录为本技能上两级，命令入口为 `scripts/studio.py`。本技能只组织工具，不规定题材、语言、时长、比例、音色或剪辑模板。

## 需求与风格

先读 `profile`、`styles list`；继续项目时先读 `status --run`。已说明的题材、参考和要求直接采用。用户尚未提供题材时只询问题材/目标；允许用户委托选题。热点任务再联网核实事件时间，普通题材不套近72小时窗口。

风格可以是库中名称、自由描述、参考脚本/视频，或不指定。展示库中实际存在的名称、描述、版本与未验证状态；不预装推荐模板。用户给出风格名称时匹配真实条目；重名要消歧，不能凭相近名称代选。自由描述可仅用于本次；用户要求保存、复用或明确“记住此风格”才调用 `learn-video-style`。仅分析参考不意味着要保存。

选择已保存风格后用 `styles show --selector <id@version>`，实际读取返回的 SKILL.md 和 style.json，与本插件工具技能组合使用。每次新聊天都查目录，不依赖聊天记忆；不存在的风格说明缺失，不编造规则。未指定风格且没有用户保存的 default_style 时可按本次需求创作，不把这次选择自动存成默认风格。

建立 brief：题材、目的/受众、输出规格、语言、时长范围（需要时）、旁白/字幕/声音要求、风格或 null、用户覆盖的规则。只问影响成片的缺项，可按使用平台给出合理建议并注明假设。用户当前要求 > 本期风格覆盖 > 选择的风格 > 用户保存偏好。格式限制来自实际工具能力，不来自旧模板。

通过 `new --title ... --brief ...` 保存；参考 [记录格式](../../references/operations.md)。选择风格会在 run 内保存不可变版本快照。续做读取快照；库里新版本不会自动替换它。

## 按任务加载工具

- 缺依赖或首次配置：`setup-video-studio`。
- 查资料、选材、下载、检查来源：`video-source-tools`。
- 项目、导入、镜头、MG、转场：`chatcut-edit-tools`。
- 配音、音乐、字幕、同步：`video-audio-tools`。
- 完整声画验收、问题定位与修复复查：`video-quality-review`。
- 导出任务与文件交付：`video-delivery-tools`。

先用题材与风格共同形成 material_plan，再找素材：题材限定内容真实性和对象；风格确定景别、运动、留白、动作长度、同期声等采用标准。已有素材先评估缺口，不为完成表格重复下载。参考视频的素材不自动成为新片的素材。

每段记录叙事目的、来源或生成资产、画面意图、真实时间范围；有事实主张才需要对应事实来源，有旁白才需要真实音频时序。纯画面、长镜头、静帧、无配音、横屏等均可由本次要求决定。

选题和制作已获授权时持续完成，不强制逐阶段批准。仅要求方案/分析时交付方案/分析。恢复未知外部任务先查实际状态，操作去重见运行记录。未请求发布或定时执行时不扩展任务。
