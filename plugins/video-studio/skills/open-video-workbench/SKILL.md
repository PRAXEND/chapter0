# 打开视频工作台

插件根目录是本技能上两级，网页代码位于该根目录的 `workbench/`。

运行 `node <插件根目录>/scripts/open-workbench.mjs`。启动器核对数据目录、版本、代码目录及风格目录，仅复用身份相同的服务；未启动时在后台启动并等待实际就绪。旧版服务缺少身份或目录不符时会报错，不能把已有地址当成本次新版本启动成功。先确认原任务是否仍在执行，保留项目；空闲服务按已有更新授权重启，正在执行时不停止任务。只依据返回 JSON 判断成功并使用其 url。缺少 Node.js 20+ 或其他端口冲突时报告实际错误，不覆盖其他服务或修改账号配置。

成功后通过当前宿主可用的浏览器打开工具展示返回的地址；Codex 的 `open_in_codex` 可用于打开浏览器面板。宿主无法自动打开或返回 queued 时给出可点击链接并说明尚未确认打开。不要以此为由重新创建视频项目。

项目、素材缓存和 Token 记录存于用户应用数据目录，不写入插件安装缓存；返回的 `dataDirectory` 是实际位置。`VIDEO_STUDIO_WEB_DATA` 可指定已有数据目录。

打开页面不授权采集、生成或导出。网页后续点击遵循[工作台约定](../../references/web-workbench.md)；制作仍使用已安装并登录的 ChatCut 及用户确认的方案。

首次打开时提醒用户完成页面上的“桌面执行会话”配置：在 Codex 桌面新建专用会话、开启完全访问、发送一条消息后回到页面选择并保存。具体步骤与权限边界见 [首次使用桌面执行会话](../setup-video-studio/SKILL.md#首次使用桌面执行会话)。已保存配置不重复要求建窗口；开始制作前会复核。打开页面和配置检查不会派发制作任务。
