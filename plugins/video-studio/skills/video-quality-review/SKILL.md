# 完整成片验收

本技能独立于制作风格与导出操作。可被制片流程调用，也可单独验收用户已有项目/视频。验收依据是用户要求、选定风格和真实媒体，不建立快切、男声、静帧长度等通用模板。读取 [验收记录与方法](../../references/quality-review.md)。

## 工具使用

- ChatCut 项目使用当前环境的 verification、visual-analysis 工作流，读回实际时间线和最终合成帧/序列；原素材帧不能证明叠加后的遮挡结果。参数以实时工具 schema 为准。
- 音画/字幕诊断按 [诊断格式](../../references/diagnostics.md) 调用 review_sync.py，明确真实说话轨道、最终 ASR、字幕和源剪点；缺少证据保持未验证。
- 配乐停顿和 ducking 候选用 review_music.py；它不判断情绪适配，也不替代全混音听审。
- 本地 ffprobe 检查流信息，FFmpeg 完整解码并可用 blackdetect、freezedetect、signalstats、silencedetect 定位疑点；报告保留参数、时间区间和局限。正常场景切换可能产生候选，同亮度错帧可能漏检，候选必须回看。
- 完整播放和逐帧查看使用当前宿主实际支持的播放器/视觉工具。无法获取连续序列或声音时明确记未验证，不用一张截图或波形替代。结构化记录用 studio.py record，汇总用 audit。

## 建立真实检查范围

读取当前 brief、所选风格快照、完整时间线（全部页）、实际导出 MP4、外置字幕及实际音轨信息。没有工程时仍检查成片，将无法定位的轨道关系列为未知，不要求用户重建工程才开始。

有风格分镜时按 [风格落实核验](../../references/style-storyboard.md) 对照计划、真实设计结果和参考节点。核验核心表达是否弱化，逐项解释替代和未实现内容；对象/特效数量不是匹配程度。style_match 绑定当前 style_plan 哈希，不因通用声画质量通过而自动通过。条件手法确实不适用时按计划记录，无需为凑齐手法而新增效果。

先完整正常速度观看和听审，再检查全部事件边界：素材入出点、源文件内部剪点、变速点、转场首尾、叠加层/遮罩/MG首尾、字幕出现消失和换句、音频拼接与淡入淡出、片头片尾。每个边界查看前后上下文，再逐帧检查瞬时异常；上下文长度按效果决定，不只看一个缩略图。运动段落还要连续播放，抽帧不能证明顺滑。

对未标注的闪动做整片逐帧扫描或使用可用的检测器辅助定位，再回到原分辨率画面核实。亮度/场景变化只能发现部分候选，同亮度闪帧、文字闪烁、边缘跳动和叠加层单帧缺失必须结合实际像素和连续播放检查。宿主无法完成的检查如实记 unverified。

## 每项都要作出有证据的结论

1. **音画同步**：对白口型、动作与拟音/节拍、解说所指对象及数字/动画、现场声，检查起点与结尾及全片累计漂移。按实际 fps、源窗口、播放速率和最终词时间核对；字幕与语音同步单独检查。不同叙事有意声画错位时按本期意图判断，不能盲目对齐。
2. **素材与图层遮挡**：检查最终合成的层级、遮罩、透明度、裁切、变换和重叠时间。主体、脸、手、操作对象、关键文字、数据及字幕是否被其他视频、图片、MG、字幕或平台安全区挡住；检查运动过程中和转场过程中是否短暂穿帮、露底或互相压盖。有意遮挡必须符合本期设计，不能因两层相交就判错。
3. **背景音乐**：实际听整段混音，判断风格、情绪、节奏是否适合内容；人声能否清楚听见，演唱是否争抢、音量是否突升/突降，ducking释放是否回弹，循环拼接是否接得上，淡入淡出是否自然。检查片头片尾、停顿、段落交界、噪声、爆音与削波；响度数字不能证明合适。没有BGM时按实际音轨证据记不适用。
4. **转场与剪接**：每个切点/转场首中尾及上下文，检查源 handles、前后镜头残留、时间线空隙、重复帧、冻结尾帧、黑边/露底、主体跳位、运动方向和叙事连续性。硬切也检查；有意跳切和速度变化遵循风格，不强行加转场。
5. **字幕出现与消失**：逐句检查真实词时间、进出动画、首尾读完时间、换句、换行、位置和基线稳定。检查过早/滞后/拖尾、重叠、闪一下消失、孤字、抖动、剪字、换行重排、背景对比、安全区、字体缺失及编码。烧录画面、Caption Cards 与外置SRT分别检查，不能互相替代。
6. **闪动与顺滑程度**：扫描单帧/数帧错画、黑白闪帧、旧素材残帧、透明层开关、亮度/颜色突然跳变、重复/丢帧、异常定格、速度断点及MG/遮罩跳变。区分素材自身频闪、生成抖动、显示/编码问题与有意设计，不自动消除风格效果。高风险区正常速度与逐帧各看一次。
7. **其他细节**：完整画面和声音是否缺失；输出比例、尺寸、fps、时长、清晰度、拉伸、色差、边框、裁切；文字错别字/专名/数字、图表单位和事实；音色/发音变化、呼吸切断、双重声音、左右声道异常；片头片尾是否截断、留尾、黑场或残音；导出与工程是否一致、文件能否完整解码、字幕文件是否完整。

## 问题闭环

每个问题记录 check、时间区间/帧号、受影响 item/track（可得时）、严重程度、现象、证据和修复建议。症状与推测原因分开。技术检测“未发现候选”不能填写感知检查通过。

已授权修改时定位最小范围修复，重导出后复查问题区间与相邻切点，重验所有受影响检查，最后完整播放新的成片。不用旧哈希或旧片段证据给新导出放行。仅要求验收时交付问题列表，不擅自改剪辑。

按每项记录 pass/fail/unverified；真实不适用项写明依据。脚本的 completed 要求全部适用项通过且没有未解决问题。最终报告显示整体结论、每项状态、问题时间点、已修复/未解决项和实际未验证范围。导出工具只处理交付，不代替此技能。
