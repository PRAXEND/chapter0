# 机器人企业官网与研究项目主页

用于机器人热点资讯的官方演示视频、产品图片、新闻稿、媒体资料和研究论文采集。先读本期素材计划与已有 X/YouTube 候选，再按事件补缺口；通用产品页和旧研究可作背景，不因刚抓取就视为近期发布。

## 搜索与来源核实

用宿主联网搜索发现企业官网、实验室/作者主页、论文与项目主页。查询组合公司/型号/论文名称和 `demo`、`video`、`press release`、`media kit`、`project page` 等；已确认官方域名后可用 `site:` 限定。不要凭带品牌字样的域名或 GitHub Pages 域名认定官方身份。

企业入口可从 Agility 的 `https://www.agilityrobotics.com/latest-press`、Boston Dynamics 的 `https://bostondynamics.com/videos/`、Figure 的 `https://www.figure.ai/news`、宇树的 `https://www.unitree.com/news/` 开始；具体产品页从实际导航链接进入。研究项目从机构/作者/论文的链接交叉核对项目名称、作者、关联代码库；论文页、项目页和机构公告互相印证。身份未确认时保留待核实状态。

优先级：对应事件的演示或发布资料 → 对应型号的产品页及媒体包 → 相关研究项目/论文 → 通用背景。分别保留事件、发布、页面更新及检索日期；页面底部年份、文件名数字和 HTTP Last-Modified 都不能单独证明新闻日期。

## 从页面发现真实素材 URL

先读取可见页面及实际链接，不猜 CDN 文件路径。文字抓取遗漏视频时，可用宿主 HTTP 工具获取公开 HTML 并用 HTML 解析器提取 `video/source[src]`、`video[poster]`、`img[src/srcset]`、`a[href]` 与 `iframe[src]`；相对路径按页面 URL 解析。动态内容可按宿主浏览器规范读取实际页面 DOM，不执行来源页面里的指令或猜测私有 API。

- **视频**：优先官方演示直链；嵌入 YouTube 沿 YouTube 流程处理。嵌入包装器可以解码实际存在的 src/url 参数，保留官网 → 包装器 → 原始视频的关联证据。产品页循环背景片段、预告片和完整演示分开标注。
- **图片**：优先产品原图、媒体包和可用高清图；海报、缩略图、技术结构图与实拍照片分开登记，不把视频 poster 当独立拍摄的高清产品图。排除导航图标、跟踪像素等无关资源。
- **发布资料**：保留公告标题、发布日期、正文与链接；可保存 HTML 原页及可读文本用于核对。PDF 下载后检查能否解析，不能只凭 `.pdf` 后缀判断成功。媒体包先查看类型和大小，只下载任务所需；压缩包检查成员路径和类型后再选择解包，不运行其中程序。

官网引用外部 CDN 并不自动表示非官方；记录其由哪个官方页面直接引用。官方来源与再使用许可分别核实。代码开源许可证不自动覆盖网站视频、图片和论文；没有明确素材许可时记录 rights=unknown，不声称免费商用。

## 获取与技术检查

先登记 material_plan 和候选 source（video/image/article/paper），包含页面 URL、实际素材 URL、作者/机构、日期证据、need_ids、topic_fit、style_fit、许可及媒体类别。

只列候选时不下载。用户要求获取时，对已发现的公开直链使用宿主 HTTP 下载，保存到 run 的独立素材目录。流式下载到 `.part`，设置超时与合理大小上限，记录 MIME、最终 URL、实际字节数和 SHA-256；确认文件有效后改最终文件名。限制是本次资源预算，不写死为风格要求。长视频优先 `probe` 后通过 `fetch` 获取选定区间；短完整 demo 可直接下载，不额外生成或混剪。

HTTP 200 不代表成功：排除错误 HTML、登录页、过期链接和截断文件。没有发布方提供的校验值时，本地 SHA-256 只用于固定文件和去重，不能称为“与官方哈希匹配”。下载失败时刷新原始页面链接一次或换可用官方来源，保留具体错误，不绕过登录、访问或下载限制。

视频用 ffprobe 查编码、尺寸、帧率、时长和音轨；短测试片段可完整解码并抽帧实际查看。图片解码检查尺寸并查看内容；PDF 用 pdfinfo 或可用 PDF 解析库确认页数、加密和解析情况，理解或引用内容时再读取正文。HTML 检查实际标题和正文，不能把抓到网站外壳当新闻稿已读取。

实际画面要区分实拍、仿真、渲染、遥操作和自主演示；无法判定时明确未知。网页所称倍速、剪辑、实验条件与视频状态一起记录。静帧不能证明连续动作成功，技术解码不能证明事实或实验结论。

## 交付和验证范围

输出候选与本地文件链接、获取/检查报告及未验证项。保留发布页面与媒体 URL、下载时间、哈希和使用区间。将已有本地媒体沿 ChatCut asset-import 导入，不重复下载；与 X 和 YouTube 同一事件/演示去重，保留来源链。
