# ChatCut 编辑工具

沿当前已安装 ChatCut 技能与实时 schema 操作，不硬编码缓存版本、assetId 或工具参数。首次连接读 chatcut-plugin-basics；桌面和 hosted 表面使用各自适用说明。

新片正式排镜或制作 MG 前，遵循 [video-project 的文案与分镜确认步骤](../video-project/SKILL.md)，检查当前方案已确认或用户明确跳过确认。确认选材不等于确认剪辑方案；已授权的局部修改不重复审稿。

按 [风格分镜与实现记录](../../references/style-storyboard.md) 读取已确认 design。先用真实素材验证有代表性的复杂节点，再扩展全片；这是内部制作检查，不新增批准环节。为每个设计登记实际 item、帧范围和证据；替代方案须保留表达目的，未完成如实记录。主体保护通过移动、跟踪、退场或重排解决，不能自动把整个风格降为固定栏位和简单弹字。

1. 读实际项目状态；新建项目后保存返回的 projectId/timelineId/editorUrl，并展示编辑器链接。使用用户指定项目时先读其时间线。
2. 导入文件加载 asset-import；使用其当前 loopback 或上传助手。保留每个来源为独立可编辑资产、原片偏移与 assetId。
3. 剪辑意图来自本期 brief 和风格快照。统一将秒转换成实际 fps 的帧；读取完整时间线所有页；区分源时间、时间线帧、变速后时长。不要把估计的生成时长用于最终排镜。
4. 保留画面、声音、字幕与MG可编辑轨道。无旁白作品可跟随动作、音乐或既定镜头时序；有旁白作品按本期约定与真实词时间对齐，不强制所有视频旁白驱动。
5. MG 加载 create-motion-graphics；暴露可编辑文字、颜色与布局。参考风格只决定表现，代码和资产绑定由工具技能处理。检查实际合成序列，静帧不证明动画。
6. 转场、滤镜、调色加载 shader-gen 并检查已有能力；检查 source handles 和跨切点读取范围。不同镜头比例按主体与风格需要布局，不能以铺满画面为由丢失关键内容。
7. 写入后读回时间线并检查实际合成画面，修正受影响区间。FFmpeg 用于获取、探测和诊断；主成片在 ChatCut 内保持可编辑。

MG 的自然画布尺寸在创建时确定；当前 hosted `edit_asset` 拒绝修改 width/height。需要改变源画布比例时创建正确尺寸的新 MG，再用一次 `edit_item` 原子替换，保留原片段时序与层级。全幅暗化、四象限等覆盖整屏的 MG 使用时间线尺寸；字幕托底等窄条使用实际窄条尺寸并定位。不要依赖子元素超出 MG 自然画布，实际渲染可能裁掉外溢区域；也不要用媒体 crop 参数制作 MG 窄条，当前 hosted MG 添加路径会拒绝该参数。

手动裁切时先确认实时工具的坐标语义。当前 hosted 编辑器的 `crop*` 裁掉完整 item 矩形的一部分，不会自动把剩余内容放大或移到矩形起点。若目标可见宽度为 W、左右裁切比例为 L/R，可用完整 item 宽度 `W / (1-L-R)`；高度按原素材比例计算；完整 item 的 left/top 再减去左/上裁切对应的像素。不要与会重置 crop 的 `fit` 混用。先用一条素材的真实合成帧确认，再复制到多屏；检查动作全过程及字幕保护区，不能只确认人物面部已裁掉。资料图的局部放大应先后保留完整图或明确局部标签，避免被裁掉的说明改变含义。

外部提交前用运行记录 operation 保存输入和 intent key，拿到实际 ID 立即写回；结果未知先查询，不盲目重提。用户没有要求的额外生成不因选了某种风格而自动获授权。

若 hosted 批量导入返回部分成功，其他条目明确报 `Idempotency key conflicts with an existing browser job`，逐项保存结果，保留原 assetId，仅把已明确失败的文件拆成单文件调用重试，每个调用使用独立幂等键或当前工具的默认键。不要把整个批次重新导入，也不要将这条恢复路径用于结果未知的超时；超时仍先查资产与任务。此为已观察到的批量键冲突恢复办法，以实时工具行为为准。
