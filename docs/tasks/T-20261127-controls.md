# 工作台控件状态、草稿与请求回执

基线 `3ef69fc`。用独立资料库和系统 WKWebView 验证。下表记录触发条件、产生的效果和保留的输入，可用作人工操作清单。

| 位置与操作 | 可操作条件与效果 | 冲突或切换时的表现 |
|---|---|---|
| 新建、切换三种入口 | 选题可给要求、事实网页与媒体直链。脚本可同时提供媒体。访谈可以先建工程，开始精剪需选择视听原片。 | 公共名称、要求、文件、画幅与时长保留，各入口自己的脚本、来源和风格选择可恢复。只用工程素材时外部链接输入暂停生效，手工导入仍可用。 |
| 新建、创建并开始 | 两按钮共用一项提交；输入符合有效时长范围。 | 重试同一创建意图返回同一工程。已创建工程若导入或开始失败，可在该工程继续剩余步骤。文件选择、未提交草稿保存在本次窗口内。 |
| 对话、暂停、续作、计划确认 | 无任务时可直接制作。制作期间需填写本次新指令。预览或导出中，按钮注明会暂停当前任务后改稿。计划确认绑定展示版本。 | 保存暂停时不能再次改方向。导出、预览和本地粗剪互斥。新指令、待保存设置和本片稿件按工程保留。 |
| 时间线、检查器、插入与回看 | 支持选片、定位、逐帧、拖移与修剪、轨级显隐静音与锁、分割、删除、吸附、缩放、复制粘贴、撤销/重做。可播放区间和选区决定各操作。 | 锁定保留查看原片与解锁；编辑字段、删除和分割受保护。修改同工程时沿用起始修订，重复请求不叠加。播放快捷键在原生对话框中暂停响应。 |
| 文本、位置、动作与高级检查器 | 普通字幕、音量、窗口、取景、组件参数与音效分别保存。已有多点取景可在高级面板修改。基础位置会平移已有动效关键帧，手工填写的关键帧优先。 | 各项目各片段的草稿独立。长度修改使用源时钟裁切，再移动起点。固定速率与长度分别提交，修改其余字段会保留变速和取景曲线。 |
| 素材与原句 | 上传本地文件、手选直链、试听原句、恢复原句各自独立。检索候选可同时选择多项，分段录像需有效源区间和确认权利。 | 数据返回绑定发起工程。其他工程的搜索结果、来源、选择和原句不会在当前面板执行。 |
| 风格、交付 | 可浏览可用发行风格，已采用的版本显示当前状态；按可用模板与选区插入。交付项按实际文件、问题时间点及候选回执开放。 | 过时的风格响应不能覆盖用户随后选择。审片意见加入当前工程的改稿草稿。实际可用目录遵循已发行版本。 |
| 工程、字幕、发布与共享 | 可改名称、稿件、时长、字幕显示、发布文案、是否分享文字和图像。画面分享及自动回看分别控制独立终审。 | 设置草稿跨标签和工程。并发改变同字段时可采用草稿或当前工程值。数据库继续拒绝迟到的起始修订。 |
| 本期声音、个人音色、音乐 | 同期声、系统/本地预置、导入录音及克隆分别判断所需材料。登记个人音色独立于本片所选声音。配乐指定素材和原创曲可选择已导入音乐。 | 切换音色参考不会沿用另一个录音的授权。试听、保存和用个人音色共用提交状态。现场录音与本地配乐可以同时使用。 |
| 外部作曲、账号、组件与窗口 | 云作曲需已保存授权、足额预算、本地账号连接和完整请求。已有不明回执先核对。账户连接、组件准备与切换帮助均能显示相应状态。 | 未提交密钥和系统登录不进入草稿。云作曲重试沿用同一回执。关闭设备窗口后，迟到的读取不会把它重新打开。帮助中的点击、编辑和快捷键与工程操作分开。 |

## 验证

```sh
node --test apps/studio/test/{control-requests,control-states,project,service,timeline-ui,clip-automation,portable-style,style}.test.mjs
node apps/studio/scripts/verify-control-states.mjs
```

Node 测试覆盖工程与任务幂等、SQLite 重开、克隆授权更换、来源和隐私依赖、费用条件、手势和后台队列。WKWebView 十组操作使用真实页面、HTTP 路由、临时 SQLite 与四秒合成视听素材。模拟响应延迟和一次上传失败，检查重新进入工程和补导只产生一项。曲线镜头从 48 帧裁到 36 帧后，播放器打开原片第 8–38 帧。另一个成员在独立窗口复测，改增益时中间取景保留，修改基础位置后两处动效关键帧一起移动。测试使用本机临时资料库。
