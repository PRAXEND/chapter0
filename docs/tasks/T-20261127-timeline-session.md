# Mac 工作台的剪辑时间线与后台会话

负责人为本机独立工作台维护者。基线为独立视频仓库 30939fc。本次使用已有工程和媒体验证剪辑，保留用户工程中的实际剪辑决定。

## 投入使用的交互

- 五轨时间线上显示实际原片缩略图、原音频波形、字幕和动效名。点标尺或空轨定位，拖橙线看帧，空格从指针开始播放。时间码支持帧号，左右键逐帧移动。
- 拖片段中部移动，拖边缘修剪，在原片边界停止。临近播放头或其他片段边缘时跨轨吸附并显示对齐线。Option 临时解除吸附，N 切换。Shift 或 ⌘ 多选，Option 加左右键按帧微移，叠加 Shift 按秒微移。
- 支持缩放、横向滚动、复制粘贴、锁定、静音、隐藏、分割、普通删除和同轨波纹删除。对 JSX 组件，可以在检查器修改时长、内容和内部出场点。用户和 Codex 仍使用同一个版本化工程。
- 一次手势对应一次持久修改。撤销重做在重启后保留，无关的 Codex 改动得到保留，受锁定或发生冲突时执行前有反馈。后台轮询在手势中延迟重绘，旧版本响应无法覆盖后续编辑。
- [OpenTake 的吸附实现](https://github.com/appergb/OpenTake/blob/main/web/src/lib/snap.ts) 与 [WeftCut 的剪辑和历史功能](https://github.com/WeftCut/WeftCut#A-complete-editor-underneath) 用于核对操作。这一轮集中在时间线基本剪辑。工程仍使用固定轨道，多机位、嵌套序列和高级曲线编辑不在本轮实现范围。

## 工程和媒体验证

- 可复验入口为 apps/studio/scripts/test-webview.mjs、verify-timeline-player.mjs，以及 test/timeline-ui.test.mjs、timeline-playback.test.mjs、timeline-source-phase.test.mjs。用已安装风格包与 LFS 实体媒体运行完整回归，源工作区存在指针文件时不宜用它代替发行资源。
- 系统 WKWebView 检查播放头、吸附导线、拖动中不写工程、双端修剪底层命令、分割、锁定、撤销及重做。用已有竖版机器人新闻工程的隔离副本检查第 1503 帧，拖回第 271 帧后从那里播放、暂停及步进一步。用户当前工程不作为测试写入目标。
- 变速 1.25 倍的 Atlas 基准片在片段内第 13 帧分割。比较 44 帧画面和 70,400 对立体声音频样本，前后逐字节一致。另一个已导出工程持续划过 12–116 帧，WebKit 实际显示 19 个中间帧，最终落到第 118 帧。更改工程版本时立即清掉上一版的帧。
- 有匹配的冻结 MP4 时验证实际文件与快照。修改后的工程直接合成当前帧，播放时按需准备六秒有声预览，复用缓存。56.375 秒科普工程首次看第 1082 帧约 0.71 秒，首次准备该处六秒播放窗口约 3.13 秒，缓存命中约 1 毫秒。持续快速拖动可跳过中途来不及合成的帧，停止后显示目标帧。
