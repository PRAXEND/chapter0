# 技术科普 v8 与月面成片的实际剪辑质量

2026-11-23。本地独立工作台的比较基线为 `0f894db`。本次检查选题入口从简报、风格加载、Codex 实际输入、素材搜索和草剪，一直到原图标注、正式渲染和交付判断。

## 历史候选与基准

三版都固定了 `henry-technical-explainer@8`。同一简报要求约 25 秒、中文、至少一处能在原照片上核对的可编辑强调，最后回到原照片。照片约束指向局部举证和片尾，其余镜头应遵循所选风格的运动画面要求。

| 文件 | 实际过程 | 成片可观察的差距 |
| --- | --- | --- |
| Atlas 技术科普 v8 基准 | 风格包内的既有成片 | 6–9 秒随着搬运动作依次加部位提示；35.5 秒左右对应仿真和实物；87–90 秒回到真机搬运回答开头。 |
| 月面 11/22 v16，24.75 秒 | Codex，gpt-6.2-astra，high。拿到风格规则；基准帧在工具输出中成了文本，两张原照取帧失败。后续合成帧能作为图片进入模型。 | 四个画面片段用两张原照片，5.38–19.46 秒连续是同一张。20.63 秒出现“留意……亮纹和暗纹”提示，画面没有移动或圈出纹路。验收仅记录转录提示。 |
| 月面 11/23 v4、v5，各 40.58 秒 | 两次均选择 local，本地素材排序与语音合成。两次均没有 Codex 创作会话。 | 各两段静图、零图形层，字幕直接使用英文图注。验收仅提示时长。 |

原先 NASA 搜索显式限定 image，Openverse 只搜图片，Commons 候选没有可用于选录像的类型。原来的基础画面渲染仅支持居中等比适应或裁切。模型得到的规则数量、工程所选风格、文件可解码、字幕时间及音轨波形都不足以证明画面执行了风格。即使底层画面是照片，字幕以外的文字也需要在正确的原片位置和时刻指认对象。

风格原文的 `video-first` 源自用户要求。它把有信息作用的运动视频、实验实录、录屏或有身份说明的仿真设为主体，并把静图留给必要的证据。风格记录里，Atlas 的 23 个主轨镜头连续覆盖基准片。月面简报中的“最后回到照片”指定的是片尾。它并未授权忽略整片的运动规则。

该组三个中间对照使用同一 `gpt-6.2-astra/high`，从会话元数据核实使用桌面 App Server `0.169.0-alpha.11.1`。历史原片使用随工作台发布的 `0.167.0-alpha.3.2`。最终复测显式固定旧片同一套 App Server 和模型，以排除该变量。每次运行有各自独立的工程与交付目录。

随包 CLI 的第一组复测中，空工程自行检索到了月面活动合辑和三张任务原照。导演没有把舷梯、登月舱远景当作靴印实验。成片 26.29 秒，全为静照，已明确记录缺少相应的动作素材。给同一简报额外提供两条实验档案来源后，25.125 秒候选从靴印实验原片取了两个窗口，合计 13.54 秒，另外 11.58 秒使用照片。颗粒黏聚的解释正确关联着陆点土力学研究。第二个实验窗口人物动作很少，镜头来自录像的时间与能清楚看见实验动作的时间有明显差距。根据原片与成片分窗抽帧，只在合计约 3.17 秒的窗口检出明显变化。它是可用的实验档案对照，风格效果仍待实看。独立判读、照片优先的边界与样本记录见[视觉证据复核](T-20261123-science-evidence.md)。

本地粗剪退出自动正式交付，工作台在播放器和交付卡显示实际引擎。用历史两张英文图注 NASA 照片走正式本地粗剪入口，成片只有画面及音乐，验收保留需修复的可播候选，输出目录没有正式交付。修订既有镜头时，Codex 和用户共用受版本约束的原图取景、几何坐标和关键帧。原版本允许提交的部分顶层位置与字号字段不会影响实际渲染，现在映射到渲染器读取的字段。

## 让源录像真正参与剪辑

素材检索可从发行者的总目录发现带逐条说明的原始影片，核对适用许可、署名和任务时间码。首个实接的馆藏是 NASA 指向的 Apollo Lunar Surface Journal，覆盖六次登月任务。真实空库中，Apollo 11 靴印实验和 Apollo 15 锤子与羽毛实验都排在各自搜索结果第一，并成功下载导入。另有独立出版社的目录结构和版权例外回归。更广的题材仍取决于可检索的馆藏与实际可用的素材。[发行者总目录](https://apollojournals.org/alsj/alsj-video.html)

对已取得的录像，导演先在本机按每秒两帧低分辨率寻找持续的局部变化，长录像限制分析量。跳切、曝光改变和整幅平移缩放单独处理。优先给 Codex 候选窗口的原片帧对，也给出低变化段，允许按实际内容否决。152 秒的靴印实验档案有 304 张本地采样帧，给模型的四对正式原片帧落在 10–15.5、25–30.5、81.5–87 和 95.5–101 秒内。D 曾采用的 63.5–70.75 秒属于低变化区。录像能看见宇航员移动和转身，分辨靴纹仍需正片照片。取材与事实分别保留来源。[靴印实验档案](https://apollojournals.org/alsj/a11/a11.mobility.html#1102525)

对于明确固定的 v8，作者保存的运动规则属于用户要求。整片经核实全是照片或冻结录像且没有照片改编授权时，工作台保留可播放的候选并要求修复。确定的整片缺失与某一次取样看不清分开处理。一般节奏建议和只在片尾返回原图的正常剪法不受影响。

## 原简报、空工程、原随包模型的最终首版

E 使用 11 月 22 日的相同简报、风格包指纹、模型 `gpt-6.2-astra`、推理档 `high` 和随包 App Server `0.167.0-alpha.3.2`。会话元数据与 MP4 均经独立读取。起始素材库为空，复测人员没有为这次运行另加网址、论文、分镜、源时间或剪辑提示。制作时使用本次修复后的导演规则与馆藏检索。系统导演从发行者目录查到 16 毫米靴印实验档案，又独立取得 NASA 任务原照 5880、5877 和着陆点土力学调查。编排轮收到 14 张原生图片，复看轮收到 7 张合成图。导演自行发现远景的框会让人误以为拍到了颗粒，移去两个框，将两处自动定格延长为连续原片。此后导出的首版没有人工改动时间线。

| 成片时间 | 实际素材与观众能看见的内容 |
| --- | --- |
| 0–5.92 秒 | 实验原片 10.00–15.92 秒，宇航员从画面右下进入，提出靴印纹路的问题。 |
| 5.92–9.58 秒 | 靴子与月面的任务近照 5880。6.21 秒起显示可编辑青框及标签，能看到横纹，框也带到了靴底边缘。 |
| 9.58–20.79 秒 | 同一机位两段实验录像，源片约 25–29.96 与 81.5–87.75 秒。可见宇航员换重心、转身、移动。两段分别解释细颗粒和轻微黏聚力，工程事实索引指向 1970 年土力学研究。人物动作没有把这两个机制展示出来，字幕和配音承担了主要解释。 |
| 20.79–27.42 秒 | 撤去框，换完整靴印任务原照 5877，旁白提醒照片能显示纹路，测不出黏聚力。 |

MP4 为 1280×720，H.264/AAC，24 fps、658 帧。411 帧（17.13 秒）来自原录像，247 帧（10.29 秒）是照片。在总长 17.13 秒的六个录像窗口，分别抽查原片和成片，均检出局部变化。能进一步映射到具体观察的区间合计 305 帧（12.71 秒）。全片 SHA-256 为 `a2e265d8ef750bb4f49eb6bfd9e686db702f673a409f39ab0bd903ba23821aeb`。验收为可交付、有建议，v8 的运动是否承担了主要解释仍待观众确认。Atlas 基准用动作、标注和真机／仿真对照共同解释原理，E 的中段尚有明显差距。

原始导出报告曾保留两条已删除定格的建议，并把相同的字幕计时方法重复列为三项。新版复核依据当前前景画面移除过期定格建议，将这三处关联到一个字幕提示，可分别跳到 4.17、11.75、25.96 秒。原报告与按相同 MP4 指纹生成的独立报告同时保留。交付工程通过安装包自带 Node 服务重新导入，12 份素材全部通过指纹核对，五类轨道可见。对副本中的靴纹青框改位置，工程版本从 1 变成 2。

## 同声轨的局部改稿对照

在全新副本上锁定首尾镜头、旁白、音乐和字幕共 24 个片段，经正常改稿入口指出 9.58–20.79 秒的远景只能交代现场，要求把原因与痕迹的对应实际剪出来。F 仍使用原随包 CLI、同模型、同推理档。最终 24 项锁定内容逐项相同。两版导出的 SRT 指纹及解码后的整条混音指纹也分别一致。

实际导出中，左侧明示“原理示意 · 横截面”，先画出颗粒，随后黄色靴底剖面下压，抬起后青色轮廓留在原位。右侧同一张放大的任务靴印原照分别标出暗槽与凸棱。中段 45 个图形图层可继续编辑，其中 7 个带关键帧。这里强调的是两种状态如何对应，照片不能测出材料内部的力。F 的背景实拍占 5.92 秒，因此仅凭这次成功的局部解释也不足以判整部达到 v8。本次改稿明确提供了创作反馈，首版能力以独立空工程产出为准。

F 说明工作台已有的图形、取景与关键帧足以做出解释。默认科普导演需要在写完分镜后实际完成这些层，在原因只能通过研究和示意讲清楚时，看一下变动前、后的两张合成图。现场实拍能直接揭示过程时沿用原动作。普通风格及访谈保持各自原有剪法。

## 新默认流程的最后一次空工程验证

G 再次只收到历史简报，固定历史模型、推理档、App Server 和系统中文配音，项目的来源网址、事实网址和初始素材均为空。新版科普导演自行取得实验档案和两张原照，编排轮得到 14 张原生图片，复看轮收到 9 张真实合成帧。最终 614 帧、24 fps，共 25.58 秒。其中 340 帧（14.17 秒）来自同一条实验原录像的三个不同窗口，274 帧（11.42 秒）来自两张原照。声画均可完整解码。

0–8.21 秒的两个档案镜头交代现场。8.21–11.83 秒回看靴尖附近。11.83–17.79 秒在实验录像上绘制明确标有“原理示意 · 靴纹剖面”的图解，黄色靴纹下压、再抬起，青色轮廓留下槽。17.79–21.13 秒在完整靴印原照圈出横棱，之后撤去框，让观众自己核对。本片包含 22 个可编辑图形层，11 个带多帧关键帧。与 F 相比，G 的示意更小，背后的档案录像同样在动，读图要更费力；F 使用独立底板和原照相互指认。G 的片长、录像比例或图层数不能据此换算为 Atlas 风格相似度。

G 的初次验收错列“已有强调，位置需核实”。同一个标注图层由“留下的横棱”改为“靴底留下的横棱”，几何和原件均不变，原先的逐字相同检查丢掉了标注。修复后，原件、步骤身份、画面区域、可见轮廓以及本版该阶段的复看记录均须吻合。仅在现有上下文能支持的短限定词修改时采用上述证据，并测试了缺复看、无关对象与否定文字。G 第 18 版通过最终安装包的正常导出入口重新渲染，两个 MP4 字节相同，SHA-256 为 `1dadcfe37d2ec04b92cd14e9d304999b2d6d28151fce597ab695525404a3d170`。正式分级为可交付、有建议，唯一建议是长句内部的一次换字幕时刻使用了估算。三条历史失败候选在同套实际验收中均为需修复。

可编辑图解和实拍来源分别记数。F 的图解显示 269 帧（11.21 秒），其中靴底下压、抬起两个关键帧动作合计 41 帧（1.71 秒），通过了独立的成片像素验证。G 使用文字字形绘制部分几何，独立图解检测器尚无法为这种画法单独计时；上文对 G 剖面的描述来自导出画面和工程。真录像、照片底图、辅助示意可同时出现在同一时刻。

最终工作台通过 74 项自动化测试、macOS 系统 WebView 创建/编辑/锁定冒烟、本机签名及随包程序核对。G 便携工程经最终安装包重新导入，12 项素材指纹一致，标注可独立改位置。同伴按独立工作区复核了图片传递、选材及成片验收。修复安装在用户 Applications 下的独立质量验证版，未发布到共享分支。跨题材持续达到 v8、声音审美和创作者接受度仍需盲评。全量测试曾在构建并行时遇到一次安装进程启动超时，单项复测和最终全量复测通过。

## 复现与判读

- 从原交付的便携工程和验收 JSON 读取素材指纹、来源、镜头区间、取景、标注图层及验收原因。工程自身的风格版本无法识别创作引擎，需对应原生产资料库的 produce 任务与真实 Codex 会话输入记录。
- 在本机安装包的 user-packs 中找到 `henry-video-styles/media/benchmarks/technical-explainer.mp4`。对比正常速度的区间和合成帧，文字所指的部位是否看得见、标注是否跟着对象、末镜是否回答开头，这些逐项记录。
- `node --test apps/studio/test/framing.test.mjs` 验证原图里的两处已知颜色依次移动到画面中心、指示框中间透明、区间预览与全片对应帧一致。
- `node apps/studio/scripts/replay-topic.mjs <原工程 JSON> <新的验证目录>` 通过新建工程和制作 HTTP 接口，从空素材库重跑原选题。沿用原工程的参考帧及转录分享设置。可用 `VIDEO_STUDIO_REPLAY_MODEL` 固定对照模型。每次运行保留独立工程、任务、成片和验收记录。
