# Mac 工作台的双风格目录、操作帮助与高级剪辑

独立视频仓库的本地任务基线为 `3ef69fc`。本轮在质量验证通道改造已有软件。验收覆盖从新建工程到手工精剪、导出和独立看片的实际入口。测试使用隔离资料库、合成色条工程及发行包的原始参考录像。

## 怎样找到功能

- 在新建工程页选择横竖版、风格和片长。保留的两套风格为热点资讯型 v8、技术科普型 v8。包内目录、构建指纹、界面菜单、新建工程 API 和切换接口共用正式选项。当前分支移除了旧规格和其他风格包。历史工程本身携带的归档继续归该工程使用。
- 左侧「使用帮助」和页面「操作说明」共用离线手册。十个主题分别配有系统 WebView 的实际界面图。可搜索、放大图片，或在「当前界面的控件」找到按钮并定位。窄窗口会收缩栏位，系统减少透明度与增强对比度时有对应外观。
- 选中时间线片段，展开检查器的「高级剪辑」。矩形、椭圆蒙版可以移动、缩放、羽化和反选。多点取景可在原片上拖焦点并调整倍率。原生文字和图形图层可编辑位置、缩放、透明度和旋转。编辑已有 JSX 动效继续使用各自组件的出场点与参数，单独的 SRT 字幕没有可见图层。
- 录像的时间曲线使用递增的原片时间锚点。相邻点之间为恒速，可在 0.125–8 倍之间调整，保持整段片长与原片首尾。同期声按同一时钟保音高。每个画面片段支持一个静态矩形或椭圆蒙版，本版的曲线按直线段连接。
- 侧栏、工具栏和卡片使用半透明材质，剪辑监视器与时间线使用深色实底。布局调整与层级上的参考来自 [Hallmark](https://github.com/nutlope/hallmark) 和 [Apple 界面材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)。

## 同时输入与提交

| 操作 | 工程行为 |
|---|---|
| 填写多个参数、读帮助、切页或选择其他片段 | 工作窗口内分别保留工程和片段草稿，同一字段被另一处修改时提示选择要保留的值。 |
| 多次点击同一次创建或重试导入 | 一次创建具有请求标识，重试找回同一工程，导入中断可继续处理待完成的素材。 |
| 开关画面分享、自动回看、声音方式、原创配乐 | 控件按实际依赖启用，提交时还会校验关联参数。 |
| 查看工程 A 的慢请求期间打开工程 B | 请求和所操作的工程、界面版本绑定，结果不会写进 B 的界面。 |
| 已有任务时提交新指令 | 创作中的任务可接收新方向。遇到正在预览或导出的任务，按钮会说明暂停后改稿。空指令、无效片长、空时间线导出均有原因提示。 |
| 盲评研究与看片 | 冻结或提交期间锁定写入。各研究方式的样本草稿分别保存，审片人的未交判断绑定到研究与样本。 |

## 检查入口

- 发行风格包用 `apps/studio/scripts/bundle-styles.mjs` 按 Git LFS 指纹物化。两套 v8 的规格、基准片、音乐、字体和原版组件均按原作者资源验证。
- `node --test apps/studio/test/*.test.mjs` 覆盖工程编辑、渲染、原声、来源、历史回退、状态规则及风格 HTTP 契约。完整发行回归应使用已物化的发行媒体和随包 Codex 程序。
- `node apps/studio/scripts/test-webview.mjs /tmp/workbench.png` 操作真实界面的风格选择、帮助图片、搜索、保留制作要求、时间线和 JSX 预览。
- `node apps/studio/scripts/verify-control-states.mjs` 在原生 WebView 与真实 SQLite 服务间验证交互、草稿、并行提交和过期请求。
- `node apps/studio/scripts/verify-clip-inspector.mjs <带声音录像> <隔离输出目录>` 通过原生鼠标拖动变速锚点，修改蒙版、取景与图层关键帧，实际导出可播放的有声短片。
