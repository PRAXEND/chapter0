# 独立 Mac 自动剪辑工作台

基线为视频仓库的 web.39 发布提交 b6a41ee。开发分支为 codex/standalone-mac-studio，范围限视频仓库。主工作区负责集成和交付。媒体、Codex 创作、风格与审片各使用独立工作区，同伴核对接口、权限、历史证据与交付。

## 产品和接口

- 新入口为 apps/studio。Tauri 通过一次性环回入口打开本机 Node 服务；Codex App Server 每工程一条持久会话，仅开放宿主提供的项目工具。
- 项目采用整数帧、原片窗口、素材指纹、基于版本的原子编辑和轨道锁。冻结任务保存原始输入、日志、运行/续作状态以及成片证据。人工剪辑、自动剪辑和局部改稿共用接口。
- 已有 Python 风格参考读取器兼容两种存储格式。旧工作台和旧项目保留原入口。独立应用复用登记方式和文件流能力，按用户选择复制历史成片与真实来源。
- 本地音轨、原片、字幕、关键帧、配乐、真实图层与最终文件均在项目内。审片分别记录严重缺陷、一般建议和未核实要求。发布与人工验收仍需独立证据。

## 可重跑的验证

在 apps/studio 执行 node --test test/*.test.mjs。系统 WebView 回归使用 node scripts/test-webview.mjs /tmp/studio-proof.png。媒体准备、样片和构建命令见该目录 README。旧读器回归在仓库根执行 python3 -m unittest discover -s tests -p 'test_style_context.py' -v。旧 Node 套件执行 node --test --test-concurrency=2 plugins/video-studio/workbench/test/*.test.mjs，PATH 使用工作台已安装的正常 Python 和 FFmpeg。

在 8 GB M1 上以自生成的中文参考录音、获许可的开放电影片段和本机曲库制作 90 秒 1080p30 样片。已核验克隆来源、声画全长解码、可编辑工程、字幕和改稿范围。实际 Codex 恢复工程后只改了指定字幕，锁定镜头及旁白保持原样。前后台对照输入固定为公开媒体、相同图像和旁白，记录模型与推理档。人审结果由真实审片人填写；机器断言、盲评准备和人审通过分别登记。

## 实现中遇到并修正的问题

- 早期技术科普能读到风格规则却遗漏基准片；统一蓝图和参考清单，并以媒体哈希作发行校验。稀疏检出和 macOS 文件供应商可能返回空文件，发行构建须核对真实字节。
- 独立工程最初拒绝片段末端用于渐隐的关键帧，已与渲染器的尾边界约定对齐。并发编辑、锁定和疑似重复付费提交有独立回归。
- macOS 发行签名需要干净的 staging 目录。构建使用用户缓存并移除复制进临时包的 Finder 资源信息。Apple 对外公证需要真实发行身份。
- 本机全局 Homebrew 的旧 FFmpeg 和 Python 安装不完整，实际产品使用随包或经过准备的运行时。工作区中旧测试另在完整呈现的基线下复跑。

## 交付与审查记录

- 独立应用在 8 GB Apple M1、macOS 26.5.2 的系统 WebView 完成建工程、修改、锁定、重开和设置回归。冷媒体缓存使用包内 Node、Codex、FFmpeg 和 macOS 系统声跑通。系统准备与正常制片全过程均未通过 Chrome 操控下载。开发机已登录的个人账号另实测过 App Server 续作、编辑和同回合改方向。
- 物理机 90 秒 1080p30 中文克隆样片使用自行合成的测试参考音、获许可的电影片段与本机曲库。六段克隆与初次渲染共 203.38 秒，初次 MLT 渲染 68.61 秒。模型报告的峰值分配为 6,193,345,229 字节。Codex 改标点后复核仅一条字幕变化。最终发布包用真实原片生成两张带同一发布标题的封面、保存风格清单并重新导入空库，共用 89.42 秒。全片 2,700 帧可解码，0 项机器问题。便携工程重新导入后仍有 26 个剪辑对象并保留锁定。
- 从单条月面靴印选题开始，真实 App Server 独立寻找两张 NASA 原照，关联 4 项事实出处，使用 Henry 技术科普 v8 排成 4 段，输出 24.75 秒的中文成片。在真实 API 流程中发现单帧 JPEG 即使 seek 到零也可能没有解出图片，曾在生成封面时中断。修正后同一个任务从冻结的候选恢复，保留剪辑和配音并交付封面、字幕和工程。抽样语音中有四处段内字幕时点建议，照常交付。
- 两项真实 web.38 历史候选按指纹回放。冻结的 18 条验收留出样本三类入口各 6 条，机器对其中 12 条给出可交付，对 6 条已注入缺陷的样本要求修复。三题材两风格两次独立创作共 12 段。两对十秒局部创作之外，额外冻结一组 54 秒 Artemis I 整片初版。真实前台与正式 App Server 均以同一模型及推理档，从同一张 30 帧拼图、同一批原片、同一旁白音色独立选择六个原片窗口。两端各输出 1296 帧可解码成片，工程均可打开。校准、留出、风格、配对的真人评分单独保存在盲评库。评分完成前，误拦率、漏放率、风格识别率与前后台偏好均待定。
- 从空工程导入时长 1165.67 秒的 NASA 原声访谈。whisper.cpp 本机用 42.24 秒转录到 204 段；Codex 选出 10 段原声，剪成 52.72 秒。删除和恢复一段后分别为 1214、1318 帧，重复恢复无额外片段。横竖混剪用真实横片和竖版裁切派生文件，各导出两版 332 帧的 1280×720 和 720×1280 工程，局部改取景后保留锁定声轨。
- 6 秒的可播放草稿沿用完整时间线的帧时钟。对同一动画取第 604 至 663 帧，首、中、尾取帧与全片 RGB 平均差约 1.1/255。工程移动字幕后两侧的偏好样片可回放，并在各自的旧版/新版位置核对。
- 已复核视频工程 web.39 原有 258 项 Node 测试及旧风格解析器 4 项 Python 测试。使用独立的本机缓存还原完整发布树，避免 macOS 按需文件未下载影响结果。新应用的媒体、项目、权限、Codex、风格和盲评共 46 项 Node 测试全部通过；真实系统 WebView 的交互回归另行通过。
- 本机已将逐文件对照当前源码的应用安装到个人 Applications，验证 ad-hoc 深度签名，实际启动并确认本机服务响应。用包内运行时、空媒体缓存、禁用旧风格目录再次检查，账号连接成功，两个 Henry 基准片都通过内容指纹验证。已在最近工程登记月面靴印和森林两个可播放、可编辑的样例。工作台直接打开五项盲评研究，本次交付时各有 0 位审片人评完。
- 代码与构建位于独立本地开发分支。对外发行签名、公证和真实使用者验收各自登记。硬件访谈与横竖混剪复跑见 [媒体实测](../../apps/studio/MEDIA.md)。详细盲评样本来源、编辑对照与复现命令在 [风格与验收记录](T-20261122-standalone-style-review.md)。
