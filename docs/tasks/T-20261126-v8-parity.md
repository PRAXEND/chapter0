# 热点资讯 v8 与技术科普 v8 的独立工作台对齐

2026-11-26。本地质量验证版，代码版本 `84e7583`，基于 `00b333b`。验收对象为新建工程与这两个固定版本，正式旁白采用本机 Dylan。用户本轮只要求工作台工程和能力验证。

## 两个风格实际取得的资源

| 新建工程的固定风格 | 基准片 SHA-256 前 12 位 | 原版可执行 JSX | 可寻址的归档短音效 | 默认音乐 |
|---|---|---:|---:|---|
| 热点资讯 v8 | `2bf2e4e4f5b1` | 7 | 6 | 《陌生厨房｜热血节拍纯音乐》 |
| 技术科普 v8 | `eedeb259a839` | 6 | 2 | Kevin MacLeod《Wallpaper》 |

开始制片前，工作台检查固定版本风格规则和基准片指纹，核对原动效与编译器中的实际执行函数。导演可按需读取所选风格的完整章节、参考帧与参数，取景、配乐、声音落点都进入可编辑工程。Dylan 作为正式音色登记，允许用户在某个工程明确指定其他声音。两个 v8 的风格语速为 1.2 倍，以实际配音文件对齐字幕。两套 v8 均要求保留对齐字幕，可选画面内显示或只随片导出 SRT。素材不足时可以更换选材、局部重写台词或保留待核项。

## 复验

实际安装路径为 `~/Applications/Video Studio 质量验证版/Video Studio.app`。仅更新质量通道。打包经过 Swift、Rust 原生编译和 macOS 深度严格签名校验。签名包的后端和网页文件与集成源码比对一致。旧运行进程仍需重新打开才能加载全部新模块。

从视频仓库根目录运行以下检查。第一条使用实际安装包的数据与运行时，临时工程库在结束时清理；第二条是本轮选择的离线回归。两条命令均无需正式导演或制片任务。

```sh
resources="$HOME/Applications/Video Studio 质量验证版/Video Studio.app/Contents/Resources"
"$resources/bin/node" tools/verify_v8_install.mjs "$resources"
VIDEO_STUDIO_BUILTIN_PACKS="$resources/user-packs" node --test apps/studio/test/{director,director-contracts,henry-v8-assets,independent-review,portrait-review,project,v8-workbench,sources,codex-transport}.test.mjs
```

最终安装版核验通过，离线回归 82/82，通过项包含单帧图像和静态封面。开发分支同伴复核发现的无条件额外回合、过期分镜确认后额外派单、局部换镜被误读为全片长度、竖版审片在标题区取样、不同风格组件凑数，以及长标题溢出，均已在集成版修正。正式运行未使用 ChatCut MCP 或 Chrome。

## 验证边界和执行记录

- 本轮没有制作用户选题或候选，没有正式模型导演、云作曲或旁白合成。开发中误运行一条原仓风格学习测试，在系统临时目录生成了一个 3 秒黑白测试文件，测试已自动清理。后续选择的回归排除了该用例。
- 真实模型对新题材会如何选镜、动效连起来的节奏、Dylan 实际听感和整体风格辨识度，仍待用户允许制作后的对照。组件像素、原件指纹、响度指标和模拟导演各自证明对应的工程行为。
- 热点投影的原始矩阵含脱敏值，本地依据同版记录的四角复原。归档未提供可随应用再分发的新青年体，按原配方后备用 Noto Sans SC。热点背景音乐元数据注明沿用原工程输出使用条款，归档短音效注明原工程使用范围；科普《Wallpaper》按随包 CC BY 4.0 署名。面向通用产品发行时，需要相应的分发依据或取得替代授权。
- 这次对齐对象是两个固定版本的制片主流程、实际样板能力和项目选项。旧工程迁移、开发任意新 JSX 的编辑器、其它 ChatCut 产品功能、所有第三方服务的在线实测均未纳入这次验收。
