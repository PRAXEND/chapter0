# Codex 从空时间线首剪并回看冻结成片

2026-11-25。任务分支 codex/standalone-mac-studio，开发基线 04347bb。固定好奇号历史首剪的视觉素材，检验技术科普 v8 在相同输入条件下的自主创作。历史首剪的问题与计量见[上一轮排查](T-20261124-curiosity-first-cut-audit.md)。

## 入口与分工

新建选题工程时选择目标时长、风格、“仅使用工程已有素材”、分享画面并自动回看，添加素材，启动一次 Codex 制作。未启用该选项的旧工程沿用其原设置。分享转录单独开关。Codex 可以看风格、源图和任意时刻的连续源帧，自行定脚本、源区间、剪辑节奏及动效，可在同段并用多个可编辑的风格组件。工程负责素材范围、授权设置、锁定、时间轴、合成与本地测量。

可解码首版先冻结，项目数据库在同一事务中登记可播放、可编辑的首版与独立的自动复剪任务。后者校验项目、修订及 MP4 指纹，把前后、切点与检查区间的实际成片帧交给同一创作会话。导演可以追加观察任意成片时刻，编辑后检查当前草稿。声音反馈为本地测量与获准共享的自动转录；中文听感和审美仍待人试听。即使导演决定保留原剪，也分别保存两项结果。一次自动复剪后结束。从其他入口单独改稿或渲染不会递归复剪。

## 实片条件与验证入口

好奇号实验导入最早轮次的两部 NASA 录像和六张照片，八个文件逐项核对 SHA-256。另附两篇首剪当时已有的 NASA 来源文字。无输入脚本或预填镜头，无旧时间线、旧导演会话和旧审片结果。横屏 1280×720、24 fps，目标 55 秒，要求 50–60 秒，模型 gpt-6.2-astra，推理档 high。工作台只接收一次新建制片任务，两份交付分别包含 MP4、SRT、工程和验收记录。

工作台测试从仓库根执行 `node --test --test-concurrency=2 apps/studio/test/*.test.mjs`。Mac 验证版构建为 `STUDIO_BUILD_CHANNEL=quality node apps/studio/scripts/build-mac.mjs`。桌面界面探测执行 `node apps/studio/scripts/test-webview.mjs`。

## 本机结果

一次制片，经同一创作会话生成 A（修订 31）和 B（修订 33）。两版均 1315 帧、24 fps、54.791667 秒，H.264 视频与立体声 AAC 全片解码通过。两份工程分开通过实际重新导入，时间线与所有素材指纹保持一致。A 在 B 创作时锁存、B 完成后复算，MP4、SRT、工程清单与验收文件均未改变。
